# Proofreading an email

1. Fix spelling, grammar, punctuation and wrong salutations. Keep the user's voice and facts unchanged.
2. Apply requested changes only (shorter, more formal, translate). Do not add new claims.
3. Reply with the improved version first, then at most 3 bullets on what changed. Flag anything that looks wrong or risky (missing attachment mention, unclear request, wrong recipient name, missing deadline).
4. If the mail mentions an attachment ("anbei", "attached") but no file is named, ask which file.
5. If the user wants a draft, continue with `write-email` steps 5-6.
