# Email layout reference (DIN 5008 and international)

The server (`email_draft`) builds this layout itself when salutation, body and closing are passed as separate fields. This file is the reference for what it does and for writing text that fits.

## DIN 5008 (German emails)

```
Sehr geehrte Frau Müller,            <- Anrede, ends with a comma
                                     <- 1 blank line
vielen Dank für Ihre Anfrage. ...    <- text starts lower case (unless noun or "Sie/Ihr")
                                     <- 1 blank line between paragraphs
Im Anhang finden Sie ...             <- mention every attachment
                                     <- 1 blank line
Freundliche Grüße                    <- Grußformel, NO comma
                                     <- 1 blank line
Max Muster                           <- name
                                     <- 1 blank line
--                                   <- signature separator ("-- ", plain text only)
Muster GmbH                          <- signature: company, address,
Musterstraße 1, 12345 Berlin            phone, web
Telefon +49 30 1234567
www.muster.de
```

Rules:
- Left aligned (Flattersatz), no indents, no justified text.
- Exactly one blank line between blocks. Never two.
- Subject: short and specific, no "Betreff:", no full stop at the end.
- Salutation: "Sehr geehrte Frau Dr. Müller," / "Sehr geehrter Herr Schmidt," / "Sehr geehrte Damen und Herren," (unknown recipient) / "Hallo Max," (informal). Several people: ladies first or alphabetically, each on the same line or "Sehr geehrte Frau Müller, sehr geehrter Herr Schmidt,".
- Closing (formal): "Freundliche Grüße" / "Mit freundlichen Grüßen". Semi-formal: "Viele Grüße", "Beste Grüße". Informal: "Liebe Grüße".
- Phone numbers: `+49 30 1234567`, `030 1234567`, extension with hyphen `030 1234567-89`. No slash, no "(0)", no "0049".
- Dates: `17.11.2026` or `2026-11-17`. Times: `14:30 Uhr`. Amounts: `1.250,00 EUR` or `1.250,00 €`.
- Lists: one blank line before and after a list.
- Font: a plain sans serif, 10 to 12 pt, black. Calibri 11 pt is the standard.

## International (English and other languages)

```
Dear Ms Miller,

Thank you for your enquiry. ...       <- starts with a capital letter

Please find attached ...

Kind regards,                         <- comma is customary
Max Muster                            <- name directly below

--
Muster GmbH ...
```

- US formal letters may use "Dear Ms. Miller:"; keep the comma otherwise.
- Closings: "Kind regards," / "Best regards," / "Best," (informal) / "Yours sincerely," (UK, known name) / "Yours faithfully," (UK, "Dear Sir or Madam").

## What the server fixes automatically
Missing comma after the salutation, missing blank lines (after the salutation, before and inside the closing), double spaces, indents, extra blank lines, "Betreff:" and a final full stop in the subject, comma after a German closing, capitalised function words after a German salutation ("Ich" -> "ich", "Vielen Dank" -> "vielen Dank").

## What it only warns about
Attachment not mentioned or mentioned but missing, phone format, long subject, capital letters, "!!", very long paragraphs, font size outside 10 to 12 pt, invalid addresses, missing recipient.
